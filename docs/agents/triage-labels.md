# Triage Labels

| 标准角色 | 本仓库标签 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格充分，可交给 Agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 决定不处理 |

技能提到标准角色时，使用本表对应标签。
不覆盖既有标签，不创建同义重复标签。
