# 深度内容科普系列 · 标准流程（deep-fact-series）

> 来源：《未来总统的物理课》系列量产沉淀（EP01–EP15，15 集，2026-09）。
> 适用：任何"经典书/学科框架 + 最新动态深调研"的深度科普短视频系列。
> 与 `concept-short-video.md` 的区别：**每集必须先做 2–6 次真实搜索**，
> 前沿内容占正片近一半时长；防重叠审计为硬性关卡。
>
> **硬性叠加**：[`user-gates.md`](user-gates.md)。深度系列 G2 必须附分章/分拍摘要。
> 未过用户确认闸，不得绘图、配音、全量渲染。

## 0. 铁律（用户明确定性）

1. **深度，不是泛泛而谈**：每集制作前必须深度调研，把 2025–2026 最新数据、
   前沿洞察做成正片主体（至少 1/3–1/2 拍数），不是结尾一句带过。
2. **每集独立深调研**：即使同系列前集已有数据，本集主题相关的新动态也要重新搜，
   信源写入本集 `讲稿.md` 的信源表（数据 | 数值 | 信源链接 三列）。
3. **list 文字与图标绝不重叠**：用 `lib/audit_boards.py` 的 `li()`/`audit()` 程序化保证。
4. **绘图认真表达**：真实数据画成图表（曲线/柱状/天梯），关键图形用可识别剪影
   （核电站=安全壳穹顶；风机=一叶朝上两叶斜下；鸭子曲线、断轴天梯等）。
5. **先确认后制作**：G1 风格 → G2 讲稿（含信源表摘要）→ 画板 → G3 音色 → TTS → G4 冒烟 → 全量。

## 1. 标准七步管线（在 concept-short-video 七步上加审计与目检）

```
① 深调研      WebSearch × 2–6（每主题改写关键词，30–60s 超时就换词重试）
② 讲稿.md     信源表 + 逐拍表 + 取舍/数字口径（第一交付物）
③ make_boards.py   import lib/audit_boards.py；画完 audit() 全绿才 save
④ check_assignment.py plan.build.json   → 必须 TOTAL unassigned: 0
⑤ build_narration_fast.py plan.build.json --rate +25%
                （NoAudioReceived：删 <2k 坏分片 + sleep 20 重试）
⑥ check_assignment.py plan.json（二清）→ render_explainer.py → verify_media.py
                （--expect 必须等于旁白合计秒数，从 plan.json 算）
⑦ 抽帧目检（每拍至少 1 帧）：斜线穿字？图形骑缝 box？造型可辨识？
                修 → make_boards 重跑 → render --force → 复验
```

## 2. audit_boards 防重叠审计框架（硬关卡）

- 所有文字一律 `mtext()`（测量后画，出画布/超容器/超宽即抛错）；
- 列表一律 `li()`（徽章 + 左对齐文字，间距与右界断言）；
- 柱体/太阳/电池/风机等图形一律 `icon()` 登记 bbox——**柱状图的柱体也要登记**
  （曾发生"单结极限 29.4%"标签被后画的柱子盖住）；
- 场景收尾 `audit(sid)`：text×text、text×icon 两两查重（pad=3px），重叠即构建失败。
- 审计覆盖不到的，靠第 ⑦ 步抽帧目检兜底：
  a) 斜向线条（激光束/曲线）穿过文字；
  b) 图形小部件（蒸汽圆等）骑在相邻 region box 边界上（check_assignment 会炸）；
  c) 图形造型误读（杯状冷却塔被看成沙漏 → 换安全壳穹顶）。

## 3. 讲稿结构（每集 8–9 拍，2.4–3.2 分钟，旁白约 1000–1200 字）

```
s01 钩子    反直觉事实/最新新闻（负电价、饼干赢 TNT、被学生问倒的物理学家）
s02 原书    Muller 当年怎么讲（具体数字+原书观点，注明"2008 年原书"）
s03–s06 物理+深调研主体：原理 1–2 拍 + 最新动态 2–3 拍（前沿占主体）
s07 心法    穆勒三条/总统两问，用 li() 列表呈现
s08 预告    一句下集钩子 + 旗子收尾
```

叙述规则：不出现公式推导，只用加减乘除与倍数；数字口语化（"约""近"）；
禁用字形 ≈ ≠ ² ㎡ →（TTS 与字体风险），用"约/不等于/平米/x"替代；
每集 3–5 个"必须记住的数字"在结尾小抄卡复现。

## 4. 系列一致性

- 竖屏 720×1280；+25% 语速、gap 0.15s；voice zh-CN-YunxiNeural；
- 每集结尾固定"心法/清单 + 旗子 + 下集预告"；
- 收官集用"全系列数字清单"串起所有集（10 个数字逐一盖章）；
- 系列 `系列.md` 记录：集数|标题|时长|质检结论|深调研要点一行。

## 5. 交付定义（全部满足才算完成一集）

user-gates G1–G4 已通过（或用户书面豁免）+ audit 全绿
+ check_assignment 0 未归属（build 前后各一次）+ verify_media PASS
+ 抽帧目检无重叠/造型可辨识 + 讲稿.md 含信源表 + 成片 out/*.mp4。
